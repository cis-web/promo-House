# ⚡ خێرا خێرا (5 سەکۆند)

## Step 1️⃣: فایلەکانی جێگیری کنە
```
پرۆژە فۆڵدەر:
✅ index.html (نوێ)
✅ script.js (نوێ - فیکسی)
✅ style.css (نوێ)
✅ firebase-config.js
```

## Step 2️⃣: Live Server دەکاتەوە

### Option A: VS Code
- `index.html` کلیکی ڕاست
- "Open with Live Server"
- ✅ دۆن!

### Option B: Terminal
```bash
cd پرۆژە/فۆڵدەر
live-server
```

## Step 3️⃣: تاقی بکە
```
Browser: http://localhost:5500
```

```

```
✅ وێنەی گەورە = دیار
